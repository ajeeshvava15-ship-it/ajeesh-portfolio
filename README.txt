AJEESH AS — MULTI-PAGE PORTFOLIO
=================================

Files:
- index.html       Home / hero / services
- about.html       Profile / experience / education
- skills.html      Skills / tools / performance marketing focus
- projects.html    Selected work / project areas
- contact.html     Contact details / email form
- style.css        Shared responsive styling

How to use:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Replace placeholder links/content as needed.
4. For the contact form, the mailto form opens the visitor's email client. A backend/form service is needed for server-side submissions.

Content is based on the supplied resume.
